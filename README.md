# Музей

Android-приложение для посетителей музея с несколькими площадками: коллекция по залам с фотографиями, поиск, отзывы с оценками, избранное, экскурсоводы, площадки и запись на сеансы экскурсий с учётом свободных мест. Данные общие для всех устройств (SQLite + Firebase Firestore). Есть панель администратора.

Индивидуальный проект по разработке мобильных приложений.

## Возможности

- Регистрация и вход, сессия сохраняется (SharedPreferences)
- Общая база для всех устройств: локальная SQLite синхронизируется с Firebase Firestore
- Главная: экспонаты по залам с фото (TabLayout + ViewPager2 + RecyclerView)
- Площадки музея: адрес, метро, часы работы, «На карте», «Позвонить»
- Экскурсоводы: фото, стаж, языки, их экскурсии
- Поиск в реальном времени (SearchView) с фильтром по залу (Spinner)
- Карточка экспоната: описание, средняя оценка, избранное, отзывы с оценкой через SeekBar
- Запись на экскурсию: DatePicker, TimePicker по сеансам, свободные места, количество взрослых и детей, аудиогид, расчёт стоимости в реальном времени
- Мои записи с возможностью отмены
- Профиль: смена имени и пароля, светлая и тёмная тема
- Панель администратора: экспонаты (с фото из галереи), залы, экскурсоводы, площадки, смена статусов броней
- Экран «О музее»: правила посещения, вопросы и ответы, источники фото
- Портретная и альбомная ориентация с сохранением состояния

## Технологии

- Kotlin, minSdk 24 (Android 7.0)
- SQLite через `SQLiteOpenHelper`, паттерн Repository
- Firebase Firestore для общей базы
- Корутины (работа с БД в фоновом потоке)
- ConstraintLayout, LinearLayout, RelativeLayout
- RecyclerView, ViewPager2, TabLayout, BottomNavigationView
- Material Components, DayNight-тема

## База данных

9 связанных таблиц: `users`, `places`, `halls`, `exhibits`, `comments`, `favorites`, `guides`, `tours`, `bookings`. Внешние ключи с каскадным удалением. Подробная схема лежит в [doc/01_Анализ_предметной_области.md](doc/01_Анализ_предметной_области.md).

## Запуск

1. Клонировать репозиторий и открыть его в Android Studio.
2. Дождаться синхронизации Gradle.
3. Запустить на эмуляторе или телефоне.

Готовый APK лежит в разделе **Releases**.

Тестовый администратор: `admin` / `admin123`.

Фотографии картин и предметов - с Wikimedia Commons (общественное достояние, The Met Open Access CC0 и др.), подробности на экране «О музее».
