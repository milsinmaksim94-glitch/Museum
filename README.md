# Музей

Android-приложение для посетителей музея: просмотр коллекции по залам, поиск экспонатов, отзывы с оценками, избранное и запись на экскурсии. Есть панель администратора для управления экспонатами, залами и бронями.

Индивидуальный проект по разработке мобильных приложений.

## Возможности

- Регистрация и вход, сессия сохраняется (SharedPreferences)
- Главная: экспонаты по залам (TabLayout + ViewPager2 + RecyclerView)
- Поиск в реальном времени (SearchView) с фильтром по залу (Spinner)
- Карточка экспоната: описание, средняя оценка, избранное, отзывы с оценкой через SeekBar
- Запись на экскурсию: DatePicker, TimePicker, количество взрослых и детей, аудиогид, расчёт стоимости в реальном времени
- Мои записи с возможностью отмены
- Профиль: смена имени и пароля, светлая и тёмная тема
- Панель администратора: CRUD экспонатов, справочник залов, смена статусов броней
- Портретная и альбомная ориентация с сохранением состояния

## Технологии

- Kotlin, minSdk 24 (Android 7.0)
- SQLite через `SQLiteOpenHelper`, паттерн Repository
- Корутины (работа с БД в фоновом потоке)
- ConstraintLayout, LinearLayout, RelativeLayout
- RecyclerView, ViewPager2, TabLayout, BottomNavigationView
- Material Components, DayNight-тема

## База данных

7 связанных таблиц: `users`, `halls`, `exhibits`, `comments`, `favorites`, `tours`, `bookings`. Внешние ключи с каскадным удалением. Подробная схема лежит в [doc/01_Анализ_предметной_области.md](doc/01_Анализ_предметной_области.md).

## Запуск

1. Клонировать репозиторий и открыть его в Android Studio.
2. Дождаться синхронизации Gradle.
3. Запустить на эмуляторе или телефоне.

Готовый APK лежит в разделе **Releases**.

Тестовый администратор: `admin` / `admin123`.
