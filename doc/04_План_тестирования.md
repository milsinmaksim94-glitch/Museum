# Раздел 4. План тестирования (тест-кейсы)

Столбец «Результат» заполняется при прохождении тестов на телефоне или эмуляторе.

| ID | Название | Предусловие | Шаги выполнения | Ожидаемый результат | Результат |
|---|---|---|---|---|---|
| TC-01 | Регистрация нового пользователя | Приложение запущено, открыт экран регистрации | 1. Ввести имя. 2. Ввести валидный логин (например `ivan`). 3. Ввести пароль и повторить его. 4. Нажать «Зарегистрироваться» | Отображается Toast «Регистрация успешна». Переход на главный экран. Запись добавлена в таблицу `users` | |
| TC-02 | Валидация пустых полей | Открыт экран авторизации | 1. Оставить поля «Логин» и «Пароль» пустыми. 2. Нажать «Войти» | На полях EditText появляется ошибка `setError()` «Заполните это поле». Вход не выполняется | |
| TC-03 | Добавление элемента в БД | Вход под `admin`. Открыта «Панель администратора → Экспонаты → +» | 1. Выбрать зал, заполнить все поля формы. 2. Нажать «Сохранить» | Экран закрывается. В списке RecyclerView появляется новый экспонат. В таблицу `exhibits` добавлена строка | |
| TC-04 | Сохранение состояния | Открыта форма записи на экскурсию, выбраны дата, время и 2 взрослых | 1. Повернуть устройство или эмулятор в альбомную ориентацию | Интерфейс перестроился под альбомный вид (две колонки). Дата, время, количество людей и сумма не сбросились | |
| TC-05 | Удаление элемента | Вход под `admin`, открыта «Панель администратора → Экспонаты» | 1. Нажать кнопку «Удалить» (корзина) у экспоната | Экспонат исчезает из RecyclerView. Появляется Snackbar «Экспонат «…» удалён». Строка удалена из таблицы `exhibits` | |

## Дополнительные тест-кейсы

| ID | Название | Предусловие | Шаги выполнения | Ожидаемый результат | Результат |
|---|---|---|---|---|---|
| TC-06 | Вход с неверным паролем | Открыт экран авторизации | 1. Ввести `admin` и пароль `123`. 2. Нажать «Войти» | Toast «Неверный логин или пароль», вход не выполняется | |
| TC-07 | Регистрация с занятым логином | Открыт экран регистрации | 1. Ввести логин `admin` и остальные данные. 2. Нажать «Зарегистрироваться» | На поле логина ошибка «Такой логин уже занят» | |
| TC-08 | Расчёт стоимости | Открыта запись на экскурсию за 500 ₽ | 1. Поставить 2 взрослых и 1 ребёнка. 2. Отметить аудиогид | Сумма: 2×500 + 1×250 + 3×200 = 1850 ₽, меняется сразу | |
| TC-09 | Поиск в реальном времени | Открыта вкладка «Поиск» | 1. Начать вводить «Айв» | Список сразу фильтруется, остаётся «Девятый вал» | |
| TC-10 | Отзыв с оценкой | Открыта карточка экспоната | 1. Поставить оценку 4 ползунком. 2. Ввести текст. 3. Нажать «Отправить» | Отзыв появляется в списке, средняя оценка обновляется | |
| TC-11 | Пустой отзыв | Открыта карточка экспоната | 1. Оставить поле пустым. 2. Нажать «Отправить» | Ошибка на поле, приложение не падает, отзыв не добавлен | |
| TC-12 | Смена статуса брони | Есть хотя бы одна бронь, вход под `admin` | 1. «Панель администратора → Брони». 2. Нажать на бронь, выбрать «Подтверждена» | Статус меняется на «Подтверждена» (зелёный), у клиента тоже | |
| TC-13 | Тёмная тема | Открыт профиль | 1. Включить переключатель «Тёмная тема». 2. Перезапустить приложение | Приложение в тёмной теме, после перезапуска тема сохраняется | |
| TC-14 | Поворот на главном списке | Открыта «Главная», выбрана вкладка зала | 1. Повернуть экран | Список перерисовался без краша | |
